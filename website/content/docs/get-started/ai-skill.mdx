## What it is

The Kit's AI skill, `pourya-kit`, is what a coding agent reads before it writes code on the Kit: what each [Capability](/docs/reference/glossary#capability) guarantees, how to declare it and what to avoid, Capability by Capability. It is the source of the Capability references on this site, so the agent and you read the same rules. It installs from the public repository `PouryaNoufallah96/pouryakit-public`.

<Callout type="warn" title="Read from the repository, not your solution">
  Every install below takes the skill from the repository's default branch, and keeps that copy until you update it: `npx skills update` for the skills CLI, `claude plugin update pourya-kit@pouryakit` in Claude Code. Upgrading the Kit in a solution does not update it.
</Callout>

## When to use it

Before you ask an agent to write or review code that references PouryaKit packages: a [Module](/docs/reference/glossary#module), a command or query, an endpoint, an [Integration Event](/docs/reference/glossary#integration-event), a test. The skill tells the agent which reference to read for the code it touches.

## Install it

<Tabs items={['Any agent', 'Claude Code', 'Codex']}>
<Tab value="Any agent">

The [skills CLI](https://github.com/vercel-labs/skills) installs it into your project, or for your user with `-g`; `-a` names the agents to install it for. It keeps one copy and links it into each agent's folder, and `--copy` copies it instead.

```bash title="Terminal"
# Into the current project
npx skills add PouryaNoufallah96/pouryakit-public

# For your user, in every project
npx skills add PouryaNoufallah96/pouryakit-public -g
```

</Tab>
<Tab value="Claude Code">

Add the repository as a plugin marketplace, then install the skill's plugin from it.

```bash title="Terminal"
claude plugin marketplace add PouryaNoufallah96/pouryakit-public
claude plugin install pourya-kit@pouryakit
```

</Tab>
<Tab value="Codex">

The skills CLI installs it for Codex when you name the agent.

```bash title="Terminal"
npx skills add PouryaNoufallah96/pouryakit-public -a codex
```

</Tab>
</Tabs>

## Check it

```bash title="Terminal"
# The skills the skills CLI installed in this project
npx skills list

# The plugins Claude Code installed
claude plugin list
```
