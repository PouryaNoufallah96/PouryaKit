Each guide is one task, in the order you do it. The code in them is the [Proving Sample](/docs/reference/glossary#proving-sample)'s, or the [Kit](/docs/reference/glossary#kit)'s own tests'.

The guides assume a solution generated from a template: see [Get started](/docs/get-started/first-host). For the idea behind a step, follow the link to its [concept](/docs/concepts); for every rule and option, to its [Capability](/docs/reference/glossary#capability)'s page under [Capabilities](/docs/capabilities).
