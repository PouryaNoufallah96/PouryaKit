- #54 docs reconcile (2026-10-08, a new session's scratchpad held none of the harness folders above; rebuilt in `54docs/`): **`mermaid.parse` of a C4 block is lenient**: a missing `)` or an unterminated string still parses, and a `Rel` to an undeclared alias passes; a misspelled keyword (`Containr(`) or an unclosed `System_Boundary {` is refused. Use a real block with one keyword misspelled as the negative control. A prose-only docs package proves it needs no snippet harness by comparing every fenced block of each changed `.md` between `git show HEAD:<file>` and the tree (`fences.py`). `dotnet pack src/PouryaKit.Templates` (seconds) then `dotnet new install <nupkg> --debug:custom-hive <abs>` and `dotnet new <short> -n Acme.Shop --no-restore` gives both solutions for a file-level diff in about a minute.
