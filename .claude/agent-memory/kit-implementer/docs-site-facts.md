## Scaffold (#186, 2026-10-26; next 16.4.3, fumadocs-core/ui 16.17.8, fumadocs-mdx 15.4.10, tailwindcss 4.3.3, typescript 7.0.2, @biomejs/biome 2.6.3, pnpm 12.5.1)

- **pnpm 11+ reads settings only from `pnpm-workspace.yaml`**, never `package.json`'s `pnpm` field. `onlyBuiltDependencies` was removed in 11 and pnpm 12 ignores it silently (no unknown-key error even with a matching `packageManager`): with it, esbuild's script stayed unapproved and the install failed `ERR_PNPM_IGNORED_BUILDS`. The key is `allowBuilds` (a map, `esbuild: false`); `strictDepBuilds` defaults true, so an unlisted script fails the install. `ignoredOptionalDependencies: [sharp]` drops next's optional sharp and its LGPL-3.0-or-later libvips. `minimumReleaseAge` defaults to 1440 minutes. Prove a clean install in a scratchpad copy of `package.json`, `pnpm-workspace.yaml` and the lockfile.
- **`pnpm licenses list --json`** groups by licence; for a package whose `package.json` has no `license` it guesses one from a LICENSE file (MIT text gave `MIT`) and says `Unknown` for none or `SEE LICENSE IN`. The site's check reads the declared field from each reported path instead. `pnpm --dir website licences` runs pnpm's own command (a British alias of `licenses`), never the script: the script is `check-licences`.
- **CI's Linux closure on this Mac**: a scratchpad copy of the three files plus `supportedArchitectures: {os: [linux], cpu: [x64], libc: [glibc]}` installs the Linux binaries (musl ones too); import `check` from the worktree's `check-licences.mjs` with `site` set to the copy (287 packages, 0 problems). Search is proven the same way: `staticClient({ from: 'http://127.0.0.1:<port>/api/search.json' }).search(q)` from `fumadocs-core/dist/search/client/orama-static.js`.
- **pnpm 12's lockfile is two YAML documents**: the `packageManager`'s own pnpm binaries (15 entries) first, then the closure (374 entries on 2026-10-26, 282 installed on darwin-arm64).
- **The closure's non-permissive licences** (session decision 2026-10-26): `lightningcss` MPL-2.0 (Tailwind 4's `@tailwindcss/node` imports it at top level) and `caniuse-lite` CC-BY-4.0 are named exceptions in `website/scripts/check-licences.mjs`; ISC and 0BSD are on the allow-list.
- **Biome 2.6** formats YAML (exclude `pnpm-lock.yaml`), deprecates `linter.rules.recommended` for `linter.rules.preset`, needs `css.parser.tailwindDirectives: true`, lints an SVG's missing `<title>`, and takes a CSS `/* biome-ignore-start <rule>: why */` ... `biome-ignore-end` range (for reduced motion's `!important`).
- **Next 16.4 with TypeScript 7.0.2** type-checks in `next build` (a planted `TS2322` failed it) and rewrites `tsconfig.json` to add `esModuleInterop: true`: keep it there or every build dirties the file.
- **Static export shapes**: a route handler at `app/api/search/route.ts` writes `out/api/search` with no extension (octet-stream on a static server), and with `trailingSlash: true` the routes manifest redirects a last segment without a dot to `<path>/`, so the index is `app/api/search.json/route.ts`; `opengraph-image.tsx` inside a route group exports as `/opengraph-image-<hash>` with no extension, so the OG images are `.png` route folders (`app/og/image.png/route.tsx`). `next build` deletes and recreates `out/`: restart an `http.server` started inside it.
- **Fumadocs 16.17**: `RootProvider`'s `theme.hotKey` takes a predicate (Mod+Shift+D; needs a client wrapper); the default search dialog's `type: 'static'` is deprecated, so a dialog with `useStaticSearch({ from })`; its `Card` draws a 1px border and a shadowed icon and its `Callout` a side stripe, so the site has its own. The official static template is in the `create-fumadocs-app` npm tarball (`template/+next+fuma-docs-mdx+static`, MIT).
- **Headless screenshots**: `chrome-headless-shell --headless --screenshot=<png> --window-size=W,H --virtual-time-budget=4000 <url>` from `~/Library/Caches/ms-playwright/chromium_headless_shell-1243/`; dark with `--blink-settings=preferredColorScheme=0` (background pixel 13,13,15). The guard refuses it with a shell variable in the line: scratchpad `p186/shots186.py` runs it and samples a pixel. The guard also refused a `cat` loop naming the template's `example.gitignore` (it contains "git").

## Covers (#190, 2026-10-27; next 16.4.3's compiled @vercel/og 1.0.1, Node 24.21.0, codex-cli 0.164.0, Geist 1.7.2)

- **`next/og` runs in a plain Node script**: `import { ImageResponse } from 'next/og.js'` (next has no exports map, so Node's ESM resolver needs the file name), then `Buffer.from(await response.arrayBuffer())`. Node 24 runs `scripts/*.ts` by type stripping, but `next build` type-checks every `**/*.ts` (a planted `TS2322` in `scripts/covers.ts` failed it): no JSX in a `.ts` (use `createElement`), no `@/` imports, and a test that imports a `.ts` file needs `allowImportingTsExtensions`, so the cover test is an `.mjs` reading the JSON. The compiled `@vercel/og` inside next is MPL-2.0 and invisible to `check-licences`.
- **`next/og` fetches a missing glyph from Google Fonts** (`loadAdditionalAsset`, always on in `ImageResponse`), so "fonts never fetched" needs a check on the strings: the covers' test holds them to printable ASCII, which the three Geist TTFs map with U+00A0 (review R3). A tagline names only what the whole package does: "tool calls run as Operations" was false for MCP tools (review R1).
- **Satori's uneven word spaces**: it measures a word as the sum of its graphemes, unkerned, but draws it kerned, so the space after a word with kerning pairs is wider (seen at 26px in Geist, all builds). One `\u00a0`-joined line is one word to its segmenter, drawn in one kerned run: break lines yourself (a character budget) and join each line with no-break spaces. Two flex items side by side (a dimmed prefix and a name) show the same gap.
- **resvg downscales with bicubic and no prefilter**: 1024px art drawn at 128px turned thin glowing edges into dots; halving three times (512, 256, 128, each an `ImageResponse` render) matched `sips`.
- **Codex `$imagegen`**: `-i <reference.png>` before the other flags keeps a set consistent; about 2 minutes and 48k tokens per image, three at once fine; it honours an exact `1280x640` or `1024x1024`. Its PNGs (RGB, `sRGB` and `eXIf` chunks) were 0.87 to 1.19 MB; a lossless zlib-9 re-encode with the best filter strategy took 16 to 17 percent off. resvg's own RGBA covers at 1280x640 came out 0.86 to 0.99 MB: little headroom under 1 MB.
- **A `\u00a0` typed into a Write or Edit tool's content lands as the literal character**, invisible in review (`replaceAll(' ', ' ')`): grep the file for non-ASCII after writing an escape, and write one with a script that builds it from `chr(92)`.
- Biome 2.6 formats Markdown under `website/` too: `pnpm --dir website lint` failed on a README's unpadded tables until `biome check --write <file>` padded them.
- Geist's GitHub release zip (`vercel/geist-font`, `geist-font-v<x>.zip`) holds static TTF and OTF per weight and `OFL.txt`; release order on the API is not by date (v1.8.x was days old on 2026-10-27, so 1.7.2 was taken).

**Why:** each cost a probe or a failed run in #186 or #190.
