# Private publication

Read [private package guidance](../../../../docs/private-packages.md) when consuming GitHub Packages, publishing a main candidate or retrying preserved originals.

Keep the existing shared Release build/test/pack path and the package inventory in `scripts/packaging/inventory.json`. MinVer alone determines versions from full history and tags; publication downloads originals and never rebuilds or supplies a version override. A named `0.x` preview/rc version uses an owner-created `v` tag on current main followed by manual CI on main. No workflow creates a tag or GitHub Release.

Authorize only the exact successful same-repository main CI `push` or `workflow_dispatch` attempt and SHA, with successful AI/package jobs. PR receipts cannot authorize publication. Use official artifact download, bind the receipt/manifest to that provenance, and verify local original hashes. Keep the original artifact and manifest unchanged, and fail if they are unavailable.

Use the fixed GitHub Packages feed, job-scoped `GITHUB_TOKEN` and `pouryakit-private-publication` group with cancellation disabled. Run standard `dotnet nuget push --skip-duplicate`, then restore every inventory package at its exact version in a temporary consumer with fresh caches and GitHub source mapping for `PouryaKit.*`. Credentials belong only in the push/restore environment, never configuration, artifacts or diagnostics. A newer pending attempt can replace an older pending attempt; GitHub concurrency is not a durable queue.

HTTP 409 skips are not remote-byte identity proof. Named-cut automation, compatibility/progression checks and content-verified recovery in #28/#29 are closed as not planned after the owner's 2026-10-06 scope adjustment; implementing them requires a new scoped ticket. Do not claim all original #24 acceptance criteria. The active Phase 5 scope is complete; [hosted completion evidence](../../../../docs/private-packages.md#hosted-completion) records the final main CI and publication at version `0.1.0-preview.0.13`. Local workflow checks prove neither feed access nor private visibility.
